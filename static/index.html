정보원별 수집

최근 7일 목록 수집 기록입니다. 문제가 있는 정보원이 위에 나옵니다. ‘지금 수집’을 누르면 해당 정보원의 목록과 기사 원문을 확인합니다.

기사 직접 추가

자동 수집에서 빠진 기사의 URL을 입력하고 정보를 확인한 뒤 추가합니다.

확인되지 않은 정보는 원문을 보고 보완해 주세요. 직접 추가한 기사는 자동 선별과 별도로 유지됩니다.

상세 점검

분야별 원문 처리 횟수와 배정 기준입니다. 대기 기사 중 같은 소식은 후순위로 처리합니다.

‘다음 작업 1회 실행’은 자동 수집 순서의 다음 작업 하나를 실제로 실행합니다.
