# 같은 소식 묶기

## 한 줄 소개
여러 매체가 같은 소식을 보도하면 카드 하나로 묶고 "같은 소식 · 외 N개 매체"로 보여 줍니다.

## 왜 만들었나요
같은 사건 기사가 여러 장 반복되면 화면이 길어지고 중요한 다른 기사가 묻힙니다.

## 어떻게 쓰나요
1. 묶인 카드에는 **같은 소식 · 외 N개 매체**가 보입니다.
2. 누르면 다른 매체의 제목과 링크가 펼쳐집니다.
3. 카테고리 오른쪽 위 건수에 "(같은 소식 묶음 · 기사 N건)"으로 원래 기사 수도 함께 나옵니다.

## 어떻게 동작하나요
1. 기사 제목에서 문장부호를 빼고 두 글자씩 잘라 조각을 만듭니다. (예: "캐논메디칼" → 캐논, 논메, 메디, 디칼)
2. 두 제목의 조각이 얼마나 겹치는지 0~1 사이 점수로 계산합니다.
3. 점수가 0.45 이상이고 날짜 차이가 3일 이내면 같은 소식으로 묶습니다. **같은 날짜** 기사끼리는 기준을 **0.15**로 낮춰, 겹치는 제목 조각이 적어도 묶습니다. 이미 묶인 기사 중 **하나라도** 비슷하면 같은 묶음에 넣으며, 여러 묶음에 겹치면 그 묶음들도 합칩니다.
4. 관련도순·최신순 모두 가장 최신 기사가 대표 카드가 됩니다. 발행일 → 수집 시각 → 저장 번호 순으로 비교합니다. 현재 원문의 발행 시각은 저장하지 않으므로, 같은 날짜 안에서는 최근 수집된 기사를 선택합니다.
5. 카테고리가 달라도 한 묶음으로 만들며, 대표 기사의 카테고리에 한 번만 표시합니다. 상단 뉴스 건수도 대표 기사 기준입니다.

## 설정 방법
묶는 기준을 바꾸려면 `static/articles.js`의 `SAME_NEWS_LEVEL`(날짜가 다른 기사), `SAME_DAY_LEVEL`(같은 날짜 기사) 값을 고칩니다.
- 숫자를 올리면 (예: 0.55) 더 비슷해야 묶입니다.
- 숫자를 내리면 (예: 0.35) 더 많이 묶입니다.

## 알아두면 좋은 점
- 제목 글자로만 판단하므로 완벽하지 않습니다. 제목이 많이 다른 같은 소식은 안 묶이고, 같은 학회의 "개막"과 "성료" 기사처럼 비슷한 제목의 다른 소식이 묶일 수 있습니다.
- 카테고리와 정보원에 관계없이 묶습니다. 검색·기간 등의 화면 필터에 맞는 기사 안에서 대표를 선택합니다.
- 화면에서만 묶습니다. CSV에는 기사가 모두 따로 들어갑니다.

## 관련 파일
- `static/articles.js` (`titlePieces`, `similarity`, `groupSameNews`)
