# 기회·위협 분류

기사의 기회·위협은 AI 인사이트와 독립적으로 작동합니다.

- 제목에서 대상과 변화가 명확한 기사만 자동 표시합니다. 예: 우리 회사 MRI 출시 → 기회, 경쟁사 MRI 출시 → 위협, 병원 증축 착공 → 기회, MRI 급여 대상 축소 → 위협.
- 예정·검토·부정 표현, 서로 상반된 변화, 일반 연구·학회 기사 등은 자동 표시를 보류합니다.
- 미분류 기사 제목 옆에서 **기회 / 위협** 중 하나를 누르면 저장됩니다.
- 이미 표시된 기사도 **변경**에서 직접 수정할 수 있습니다. **선택 해제**는 제목 자동 판단으로 되돌립니다.
- 수동 분류는 DB에 별도로 저장되어 새로고침과 재수집 후에도 유지되며 자동 판단보다 우선합니다.
- 배지에 마우스를 올리면 ‘직접 분류’ 또는 ‘제목 기준 추정’을 확인할 수 있습니다. 영향 필터도 이 분류를 사용합니다.

기사별 AI 인사이트는 사용 여부를 결정할 때까지 생성 버튼·자동 생성·생성 API를 보류합니다. 기존 인사이트의 설명은 유지하되 ‘영향:’ 줄은 응답에서 제거하며, 영향 분류에 사용하지 않습니다. 주간·월간 리포트는 별도 기능입니다.

관련 파일: `static/impact.js`, `static/articles.js`, `src/service.js`, `src/index.js`, `src/db.js`, `schema.sql`.
