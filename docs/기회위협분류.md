# 중요 기사 기회·위협 선택

- 기사에 중요 기사(★)로 지정하면 제목 옆에 **기회 / 위협** 선택 버튼이 나타납니다.
- 사용자가 직접 선택하며 제목에 따른 자동 판정은 없습니다.
- 선택은 새로고침과 재수집 후에도 유지됩니다. **변경** 또는 **선택 해제**로 수정할 수 있습니다.
- 중요 해제 시 분류도 해제됩니다. 다시 중요 기사로 지정하면 새로 선택합니다.
- 일반 기사에는 분류를 표시하지 않으며 서버에서도 저장을 허용하지 않습니다.
- 전체 영향 필터는 제공하지 않습니다. 월간 요약의 비즈니스 기회·위협·리스크는 직접 선택한 중요 기사만 활용하고 빨간 ▲·파란 ▼로 표시합니다.

관련 파일: `static/impact.js`, `static/articles.js`, `src/service.js`, `src/index.js`, `src/db.js`, `schema.sql`.
