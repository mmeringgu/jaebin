## 장비군과 식약처 품목명

| 장비군 | 이번 조회의 대표 품목명 | 대표 코드 |
|---|---|---|
| CT | 전신용 전산화 단층 엑스선 촬영장치 | A11010.01 |
| MRI | 초전도 자석식 전신용 자기공명 전산화 단층 촬영장치 | A12010.01 |
| Angiography | 거치형 디지털식 순환기용 엑스선 투시 진단장치 | A11090.03 |
| 초음파 | 범용 초음파 영상 진단장치 | A26380.01 |

품목명 띄어쓰기는 기록마다 다를 수 있으므로 품목분류번호로 분류합니다. 명칭·코드 근거는 [국가법령정보센터 품목·등급 규정](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000275656)과 실제 식약처 검색 응답입니다.

네 장비군의 모든 세부 품목을 전수 수집한 결과가 아닙니다. CT의 부위 한정용·암형 등, MRI의 다른 자석·부위 구분, Angiography의 이동형 등, 초음파의 이동형·산부인과용·유방용 등은 본 수집에서 각각의 상세 코드로 확장해야 합니다. 치과용 CT, PET/CT·SPECT/CT 조합장비, 초음파 프로브, 조영제, 영상분석·전송 소프트웨어는 장비명 단어가 포함돼도 본체로 자동 분류하지 않습니다.

## 실제 조회 방법

출처: [식약처 의료기기안심책방 품목 및 업체 검색](https://emedi.mfds.go.kr/search/data/MNU20237).

검색 화면이 사용하는 공개 조회 요청 `POST /search/data/list`를 읽기 전용으로 사용했습니다. 기본 4개 업체 × 4개 대표 코드 = 16개 조합에서 첫 페이지(최대 10행)를 조회했고, 한국지이초음파(유)의 범용 초음파를 별도 1회 조회했습니다. 인증키나 로그인이 필요하지 않았습니다. 허가번호 단위(`GROUP_BY_FIELD_01`)로 묶었습니다.

- 기본 16개 조합: 응답 125행, 엄격한 상태·수출 조건 선별 후 87행.
- 한국지이초음파 초음파 추가 조회: 응답 10행, 선별 후 1행.
- 합계: 17개 조회, 135행 확인, 88행 표본 유지.
- 본문·모델명 키워드가 아닌 등록업체명과 정확한 품목코드를 검증했습니다.
- 정상 상태이고 취소 표시·취소취하일자가 없으며 수출전용이 아닌 표본만 유지했습니다. 허가번호·날짜도 필요합니다.
- 검색 화면의 ‘정상’ 조건을 넣어도 ‘전환’ 항목이 함께 반환되는 것을 관찰하여 반환 행에서 다시 걸렀습니다.
- `A11010` 같은 앞부분 코드로 검색하면 결과가 0건으로 나올 수 있어 대표 상세 코드 `A11010.01` 등으로 조회했습니다. 코드 앞부분 검색의 0건을 실제 등록 부재로 해석하지 않습니다.

## 본 수집에 앞서 처리할 사항

1. 장비군별 상세 코드 확장과 페이지 순회가 필요합니다. 이번 표본을 전체 허가 목록이나 최근 30일의 신규 제품 목록으로 표시하면 안 됩니다.
2. 허가·인증·신고를 모두 다뤄야 합니다. ‘수인’·‘제인’으로 확인되는 인증 기록도 포함됩니다.
3. 허가일은 제품 출시일·병원 도입일이 아닙니다. 갱신·전환 등의 가능성을 분리하고 화면 명칭은 ‘제품 인허가 현황’으로 유지합니다.
4. [Siemens 공식 eIFU 목록](https://www.siemens-healthineers.com/kr/notice/di-eifu)에 `D 수인` 번호의 CT·MR 관련 디지털의료기기 소프트웨어가 있습니다. 본체 허가와 별개인 소프트웨어 기록을 본체로 중복 집계하지 않으며, A계열 코드만으로 최신 등록을 모두 포괄한다고 단정하지 않습니다.
5. 공개 화면 조회는 이번 검증에 성공했지만 공개 API 계약은 아닙니다. 운영 자동 수집은 [식약처 품목허가 API](https://www.data.go.kr/data/15057456/openapi.do)와 [품목정보 API](https://www.data.go.kr/data/15073906/openapi.do)의 인증키·실제 응답을 확인한 뒤 연결하는 것이 적절합니다. 현재 로컬 설정에서 관련 인증키는 확인되지 않았습니다.
6. 통계 수치나 AI 요약을 추가하지 않고 회사·장비군·모델명·허가일·허가번호·상태 정도만 표시하면 기존 월간 요약과 역할을 구분할 수 있습니다.
