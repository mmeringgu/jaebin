# 정보원 상태

## 한 줄 소개
뉴스를 가져오는 매체(정보원)마다 잘 수집되고 있는지, 며칠째 새 기사가 없는지를 표로 보여 줍니다.

## 왜 만들었나요
- 매체 사이트가 바뀌거나 접속을 막으면, 그 매체 기사만 조용히 안 들어옵니다.
- 지금까지는 기사가 줄어든 걸 눈치채기 어려웠습니다. 표 하나로 "어디가 이상한지" 바로 보이게 했습니다.
- 꺼져 있던 정보원을 다시 켠 뒤(2026-11-04, 12곳 → 24곳) 계속 잘 되는지 지켜보는 용도이기도 합니다.

## 어떻게 쓰나요
1. 맨 위 **⚙️ 관리** 탭에서 **수집 관리**를 펼칩니다. 기본으로 접혀 있습니다.
2. **자동 수집 현황**에서 오늘 진행 상황을 확인합니다. **정보원별 수집**도 기본으로 접혀 있으며, 펼치면 문제 있는 정보원이 맨 위에 나옵니다.
3. 상태 글자의 뜻:
   - 🟢 **정상**: 최근 3일 안에 새 기사를 찾았습니다.
   - 🟠 **○일째 새 기사 없음**: 3일 넘게 키워드에 맞는 새 기사가 없습니다. 사이트가 바뀌었는지 한번 확인해 보세요.
   - 🔴 **수집 실패**: 가장 최근 수집이 실패했습니다. 글자 위에 마우스를 올리면 실패 이유가 보입니다.
   - ⚪ **기록 없음**: 최근 7일 동안 한 번도 수집하지 않았습니다.
4. **새로고침** 버튼을 누르면 최신 상태로 다시 불러옵니다.
5. 각 정보원의 **지금 수집** 버튼으로 목록 수집과 최대 30건의 기사 원문 확인을 실행합니다. 진행 상황과 결과는 표 위에 표시되며, 끝나면 정보원 상태와 자동 수집 현황을 다시 조회합니다.
6. **기사 직접 추가**에서 URL을 확인하고 제목·출처·발행일·분야·첫 문단을 보완한 뒤 뉴스에 추가합니다. 직접 추가한 기사는 자동 선별과 별도로 유지하며 중복 URL은 저장하지 않습니다.
7. **상세 점검**에서 최근 작업 이력을 확인합니다. **다음 작업 1회 실행**은 예약 순서의 다음 작업을 실제 실행합니다.

## 예약 수집 배분 (2026-11-17)

하루 원문 처리 시도 상한은 160회이며, 실패·선별 제외도 시도 횟수에 포함합니다.

| 구분 | 목표 |
|---|---:|
| 캐논 | 30회 |
| 정책 | 45회 |
| 경쟁사 | 45회 |
| 병원 | 30회 |
| 학회 | 10회 |

- 캐논 본사 → 글로벌 → 일본 메디컬 → 캐논 검색 순으로 목록을 확인하고, 해당 목록에서 찾은 기사를 바로 처리합니다.
- 일반 정보원은 목록과 원문 처리를 교대하며, 원문은 정책 → 경쟁사 → 병원 → 정책 → 경쟁사 → 학회 순환을 기본으로 합니다. 경쟁사와 매체도 번갈아 선택합니다.
- 캐논은 오전 20회까지 우선 처리하고, 나머지 10회는 오후 2시 이후 사용할 수 있습니다. 오후 갱신을 위해 최대 10회를 보호하며, 오후 5시부터 남은 몫을 다른 구분에도 배분합니다. 다른 구분도 후보가 없고 목록 확인이 끝났으면 남은 배정량을 재배분합니다.
- 같은 소식은 대표 기사부터 처리하고 추가 보도는 후순위로 둡니다. 제목의 수치가 다르면 새로운 정보로 취급하며, 후보를 삭제하지 않습니다. 같은 URL·제목으로 이미 게시된 후보는 자동 재처리하지 않습니다.
- 본사·글로벌 및 주요 정책·경쟁사 정보원은 하루 2회, 일본 메디컬·캐논 검색·일반 매체는 하루 1회 확인합니다. 병원신문 학회는 2일, 인사·취임은 3일, 대한병원협회는 2일 주기입니다. 대학병원 공식 보도자료 사이트는 재활성화하지 않았으며, 향후 등록하면 3일 주기를 사용합니다.
- 자동 수집 현황에는 켜짐·오늘 게시·원문 처리·대기를 표시하고, 구분별 배분과 작업 이력은 상세 점검으로 옮겼습니다., 정보원 표에 자동 확인 주기를 표시합니다. 상태 확인은 수집을 실행하지 않습니다.

## 어떻게 동작하나요
1. 정보원 목록을 확인할 때마다 "언제, 몇 건 찾았는지, 성공했는지"가 수집 기록에 남습니다.
2. 관리 탭에서 정보원별 수집을 펼치면 화면이 서버에 정보원별 기록을 달라고 요청합니다.
3. 서버는 정보원마다 마지막 확인 시각, 마지막으로 새 기사를 찾은 시각, 최근 7일 새 기사 수, 마지막 실패 이유를 모아 보내 줍니다.
4. 화면이 그 숫자로 상태(정상·새 기사 없음·실패)를 정해 표로 그립니다.

## 설정 방법
따로 설정할 것 없음

## 알아두면 좋은 점
- 수집 기록은 7일만 보관하므로, 표도 최근 7일 기준입니다.
- "새 기사 없음"이 꼭 고장은 아닙니다. 그 매체에 우리 키워드에 맞는 기사가 없었을 수도 있습니다. 병원 보도자료처럼 기사가 드문 곳은 자주 주황색이 됩니다.
- "최근 7일 새 기사"는 키워드에 맞아 새로 저장된 후보 수입니다. 이미 저장된 기사는 다시 세지 않습니다.
