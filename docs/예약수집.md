# 예약 수집 (자동 수집 배분)

## 한 줄 소개
사람이 버튼을 누르지 않아도, 매일 정해진 순서와 양에 맞춰 기사를 알아서 모읍니다.

## 왜 만들었나요
- 하루에 읽을 수 있는 기사 수에는 한계가 있습니다. (무료 요금제라 하루 160회)
- 아무 순서로나 모으면 기사가 많은 분야(예: 정책)만 꽉 차고, 정작 중요한 캐논 소식이 빠질 수 있습니다.
- 그래서 **캐논 소식을 먼저**, 나머지는 **분야별로 고르게** 나눠 모으도록 했습니다.

## 어떻게 쓰나요
따로 누를 것은 없습니다. 진행 상황만 화면에서 확인합니다.

1. 맨 위 **⚙️ 관리** 탭을 누릅니다.
2. **수집 관리**를 펼칩니다. (기본으로 접혀 있음)
3. **자동 수집 현황**에서 오늘 상황을 봅니다. 맨 위 작은 칸들에 켜짐/꺼짐, 기사 읽기 횟수, 목록 확인한 곳, 실패 수, 대기 중인 기사가 나뉘어 보입니다.
   - 구분(캐논·정책·경쟁사·병원·학회)마다 **처리 수 / 목표**, **대기 중인 기사 수**, **중복이라 뒤로 미룬 기사 수**가 보입니다.
4. **상태 확인** 버튼을 누르면 최신 상황으로 다시 불러옵니다. 확인하는 동안 버튼이 "확인 중…"으로 바뀝니다. (수집을 실행하지는 않음)
5. 바로 시험해 보고 싶으면 **자동 수집 이력·시험 실행**을 펼쳐 **다음 작업 1회 실행**을 누릅니다.

## 어떻게 동작하나요
1. 1분마다 Cloudflare가 "할 일이 있나?" 하고 깨웁니다. 한 번 깨울 때 작업은 하나만 합니다.
2. 오전 7시 전에는 아무것도 하지 않습니다.
3. 할 일은 두 종류입니다.
   - **목록 확인**: 매체의 기사 목록을 보고 새 기사 후보를 찾습니다.
   - **원문 읽기**: 후보 기사 하나를 열어 내용을 읽고 저장합니다. (하루 최대 160회)
4. 하루 160회는 이렇게 나눕니다.
   - 캐논 30 / 정책 45 / 경쟁사 45 / 병원 30 / 학회 10
5. 순서를 정하는 규칙:
   - **캐논 먼저**: 캐논 본사 → 글로벌 → 일본 메디컬 → 해외 검색 → 국내 검색 순서로, 목록을 찾자마자 바로 원문을 읽습니다.
   - **골고루**: 나머지는 정책 → 경쟁사 → 병원 → 정책 → 경쟁사 → 학회 순서로 돌아가며 읽고, 같은 매체·같은 회사가 연달아 나오지 않게 합니다.
   - **오후 캐논 몫 남겨두기**: 오후에 나오는 캐논 소식을 위해 캐논 몫 중 10회를 오후 2시까지 아껴 둡니다. 오후 5시가 되어도 쓰지 않았다면 다른 분야에 나눠 줍니다.
   - **중복은 뒤로**: 여러 매체가 같은 소식을 다루면 첫 기사만 먼저 읽고 나머지는 뒤로 미룹니다. 단, 제목의 숫자(금액·제품 번호 등)가 다르면 새 소식으로 봅니다.
6. 매체마다 목록을 보는 횟수가 다릅니다.
   - 하루 2회(오전·오후 2시 이후): 캐논 본사·글로벌, 주요 정책·경쟁사 매체
   - 하루 1회: 일반 매체, 일본 메디컬, 캐논 검색
   - 2~3일에 1회: 기사가 드문 학회·협회·병원 사이트

## 설정 방법
- 켜기/끄기: `wrangler.toml`의 `AUTO_ENABLED = "true"` (끄려면 `"false"`)
- 하루 원문 읽기 횟수: `wrangler.toml`의 `AUTO_MAX_BODY_PER_DAY = "160"`
- 분야별 배분·캐논 순서·하루 2회 매체·느린 매체: `src/config.json`의 `automation` 부분
  - 예: `"daily_targets": { "company": 30, "policy": 45, "competitor": 45, "hospital": 30, "conference": 10 }`
- 바꾼 뒤에는 `npm run deploy`로 다시 올려야 반영됩니다.

## 알아두면 좋은 점
- 한 매체가 하루 3번 실패하면 그날은 그 매체를 건너뜁니다.
- 전체 실패가 하루 10번 쌓이면 그날 예약 수집은 스스로 멈추고, 다음 날 다시 시작합니다.
- 160회를 다 쓰면 "오늘 기사 처리 상한에 도달했습니다"라고 표시되고 다음 날까지 쉽니다.
- 직접 **지금 수집**을 눌러 목록을 확인했다면, 같은 시간대의 예약 목록 확인은 건너뜁니다.

## 관련 파일
- `src/scheduler.js` (순서·배분 계산), `src/service.js` (실제 실행), `src/index.js` (1분마다 깨우기)
- `src/config.json`의 `automation`, `wrangler.toml`
- `static/automation.js` (자동 수집 현황 화면)
