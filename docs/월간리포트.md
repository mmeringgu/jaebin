# 월간 요약

**월간 요약** 탭은 최근 30일의 중요 기사를 표로 자동 정리합니다. 생성 버튼이나 생성 대기 시간이 없으며, 중요 지정·해제·숨김·분류 변경을 즉시 반영합니다. 뉴스 탭의 검색·분야 필터와는 독립적으로 전체 중요 기사를 사용합니다.

- **이번 달 핵심 동향**: 최근 30일의 중요 기사 전체를 최신순으로 표시합니다.
- **비즈니스 기회**: 중요 기사 중 직접 ‘기회’를 선택한 기사입니다.
- **위협·리스크**: 중요 기사 중 직접 ‘위협’을 선택한 기사입니다.

각 영역은 **대상 · 핵심 변화 · 영향 · 출처** 표이며, 핵심 변화에는 원문 제목을 표시합니다. 출처에는 원문 링크와 발행일을 표시합니다. 긍정 영향은 빨간 ▲, 부정 영향은 파란 ▼이며 선택이 없으면 기호를 표시하지 않습니다. 해당 기사가 없으면 빈 상태 안내를 보여 줍니다.

경쟁사 움직임은 **업계 동향 → 경쟁사**로 옮겼습니다. 최근 30일 소식을 회사별로 묶고 회수·판매중지 현황 바로 앞에 배치합니다. 같은 소식은 대표 기사와 추가 출처로 표시하며 회사별 최신 3건을 보여 줍니다.

월간 화면은 기존 기사와 직접 분류만 활용하며 AI 생성 요청이나 저장된 생성 결과를 사용하지 않습니다.

관련 파일: `static/report.js`, `static/articles.js`, `static/stats.js`, `static/index.html`.
