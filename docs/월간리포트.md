# 월간 리포트

탭 순서는 뉴스 → 월간 요약 → 업계 동향 → 관리입니다. **📝 월간 요약** 탭에서 **월간 요약 만들기**를 누르면 최근 30일 기사를 바탕으로 초안을 생성합니다.

별표 기사를 우선하고 중복 보도가 많은 다른 소식도 함께 선정하며, 최대 60건을 활용합니다. 숨긴 기사와 기간 밖 기사는 제외합니다. 뉴스 화면과 같은 [기사 선별 기준](기사선별기준.md)을 통과한 기사만 사용합니다.

리포트는 핵심 동향, 비즈니스 기회, 위협·리스크, 경쟁사 움직임으로 구성됩니다. 경쟁사 관련 근거 기사가 없으면 해당 항목은 생략하며, 각 항목에는 검증된 원문 링크가 표시됩니다.

OpenAI API 키가 필요하며 생성할 때마다 비용이 발생합니다. 생성에는 최대 2분 정도 걸릴 수 있습니다. 회의에 사용하기 전에 원문과 내용을 확인해 주세요.

주간 리포트 생성 버튼과 서버의 주간 생성 경로는 삭제했습니다. 관리 → 노출 관리의 주간·월간 추이 선택은 리포트 생성과 별도 기능입니다.

관련 파일은 `static/report.js`, `src/index.js`의 `/api/monthly-report`, `src/service.js`의 `makeReport`, `src/ai_summary.js`의 `monthlyReport` 및 `REPORT_PROMPT`입니다.
