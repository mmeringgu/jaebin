# 월간 요약

**월간 요약** 탭은 최근 30일의 중요 기사를 정책·기회·위협 표로 자동 정리합니다. 표는 생성 대기 없이 중요 지정·해제·숨김·분류 변경을 즉시 반영합니다. 뉴스 탭의 검색·분야 필터와는 독립적입니다.

- **정책**: 기회·위협을 직접 선택하지 않은 정책 중요 기사입니다.
- **기회**: 중요 기사 중 직접 ‘기회’를 선택한 기사입니다.
- **위협**: 중요 기사 중 직접 ‘위협’을 선택한 기사입니다.

같은 URL과 같은 소식의 중복 보도를 제거합니다. 직접 선택한 기회·위협을 우선해 한 기사·소식은 한 표에만 표시합니다. 정책 이외 미분류 중요 기사는 표 밖에 건수로 안내하며 뉴스에서 분류할 수 있습니다.

각 영역은 **대상 · 핵심 변화 · 영향 · 출처** 표이며, 핵심 변화에는 원문 제목을 표시합니다. 출처에는 원문 링크와 발행일을 표시합니다. 긍정 영향은 빨간 ▲, 부정 영향은 파란 ▼이며 선택이 없으면 기호를 표시하지 않습니다. 해당 기사가 없으면 빈 상태 안내를 보여 줍니다.

경쟁사 중요 기사는 월간 요약에서 확인합니다. 업계 동향에서는 경쟁사 움직임을 제거하고 공식 회수·인허가 자료와 정책·병원 현황만 대시보드로 표시합니다.

상단의 **AI 인사이트 만들기** 버튼을 누르면 최근 30일 중요 기사만 중복 제거해 분석합니다. 미분류 중요 기사도 포함하며 일반 기사·숨긴 기사·기간 밖 기사는 제외합니다. 제목·내용 재요약 대신 다음 변화, 비즈니스 영향, 필요한 확인·대응을 글머리 기호 2~3개로 작성합니다. 항목은 한 문장·100자 이내이며 ‘~확인이 필요함.’ 등의 보고체로 표시합니다. 각 항목에는 검증된 근거 원문 링크가 연결됩니다.

기사 내용에 없는 수치·일정·사실은 만들지 않고 전망을 사실과 구분하도록 요청합니다. 중요 기사 변경 시 이전 결과를 비우며, 실패 시 안내 후 다시 만들 수 있습니다. 버튼을 누르기 전에는 AI를 호출하지 않습니다. 인사이트에는 `OPENAI_API_KEY` 설정이 필요합니다.

관련 파일: `static/report.js`, `static/news-rules.js`, `src/ai_summary.js`, `src/report.js`, `src/service.js`, `static/index.html`.
