# 해외 기사 제목 자동 번역

## 한 줄 소개
일본어·영어로 된 기사 제목을 GPT가 한국어로 바꿔서 보여 줍니다.

## 왜 만들었나요
- 캐논 해외 뉴스를 모으기 시작하면서 일본어·영어 제목이 목록에 섞였습니다.
- 제목만 보고 무슨 소식인지 바로 알 수 있게 했습니다.

## 어떻게 쓰나요
1. 따로 누를 것은 없습니다. 📰 뉴스 탭에서 해외 기사 제목이 한국어로 보입니다.
2. **▸ 자세히**를 누르면 **원제**(원래 제목)가 함께 보입니다.

## 어떻게 동작하나요
1. 기사를 저장할 때 제목에 한글이 없고 영어·일본어·한자가 있으면 번역 대상으로 봅니다.
2. GPT에게 제목을 보내 한국어 제목을 받아 저장해 둡니다. 다음부터는 저장된 번역을 다시 씁니다. (같은 제목을 두 번 번역하지 않음)
3. 예전에 저장된 해외 기사는 화면을 열 때 뒤에서 하나씩 번역합니다. 화면이 느려지지 않도록 번역을 기다리지 않고 먼저 보여 줍니다.
4. 원래 제목은 그대로 남겨 두고 분류·저장에 씁니다. 번역은 보여 줄 때만 씁니다.

## 설정 방법
- AI 인사이트와 같은 OpenAI 키(`OPENAI_API_KEY`)를 씁니다. 따로 넣을 것은 없습니다.
- 키가 없으면 번역하지 않고 원래 제목으로 보여 줍니다.

## 알아두면 좋은 점
- 번역할 때마다 OpenAI 비용이 아주 조금 듭니다. (제목 한 줄이라 적음)
- 번역이 실패하면 원래 제목으로 보여 주고, 15분 뒤에 다시 시도합니다.

## 관련 파일
- `src/title-translation.js` (번역 대상 판단·저장), `src/ai_summary.js` (GPT 요청)
- `static/articles.js` (원제 표시)
