# 기능 문서 목록

> 전체 기능을 한눈에 보려면 [기능 모음집](기능모음집.md)을 먼저 보세요.

- [중요 기사 분류](기회위협분류.md) — 중요 기사에만 기회·위협 직접 선택
- [CSV 내보내기](CSV내보내기.md) — 기사 목록을 엑셀 파일로 내려받기
- [화면 편의 기능](화면편의기능.md) — 신문 브리핑형 목록, 검색(검색어 강조), 기간 필터, 정렬(관련도순·최신순), ★ 중요 표시, 분야(전체·AI·CT·MRI·UL·VL/XR·Vet), 병원·학회 나누기, 탭 구성
- [업계 동향 · 노출 관리](통계.md) — 정책 현황판·일정, 신설·증설 병원 표, 경쟁사 회수 현황(업계 동향 탭) / 회사별 언급 추이·점유율, 분야별·매체별 노출 비교(관리 → 노출 관리)
- [아침 브리핑](아침브리핑.md) — 수집이 끝나면 Slack/Teams로 주요 기사 전송
- [기사 숨기기](기사숨기기.md) — 필요 없는 기사를 목록에서 치우고 되돌리기
- [같은 소식 묶기](같은소식묶기.md) — 여러 매체의 같은 소식을 카드 하나로 묶기
- [월간 리포트](월간리포트.md) — GPT가 최근 30일 기사로 회의 리포트 초안 작성
- [오래된 기사 정리](오래된기사정리.md) — 90일 지난 기사를 자동으로 보관함으로 옮기기
- [Cloudflare 배포](Cloudflare배포.md) — 자바스크립트(Cloudflare Worker)로 바꿔서 PC 없이 사이트·예약 수집 운영
- [빙 뉴스 검색](빙뉴스검색.md) — 키 없이 빙 뉴스에서 캐논메디칼·경쟁사·특수의료장비 검색어로 일반 언론 기사까지 모으기
- [정보원 상태](정보원상태.md) — 매체별로 수집이 잘 되는지, 며칠째 새 기사가 없는지 표로 보기
- [예약 수집](예약수집.md) — 하루 160회를 캐논 우선·분야별 목표로 나눠 자동으로 기사 모으기
- [기사 선별 기준](기사선별기준.md) — 키워드가 맞은 기사 중 업무와 관련 있는 기사만 모든 화면에 똑같이 골라 보여 주기
- [캐논 해외 뉴스](캐논해외뉴스.md) — 캐논 일본·글로벌 공식 사이트와 해외 검색에서 캐논 의료 소식 모으기
- [제목 자동 번역](제목번역.md) — 일본어·영어 기사 제목을 한국어로 바꿔 보여 주기
- [Vet 분야](Vet분야.md) — 동물병원·수의대의 영상진단 소식을 따로 모아 보기
